# Purpose

This homework requires you to think about the computational complexity of problems.

# Background

For this assignment, you should
- recall the definition of decidability and undecidability
- read and write formal language notation
- prove that a language is undecidable
- recall the definition of P and NP
- understand how input representations affect computational complexity
- prove that a language belongs to P
- determine whether NP is closed under a given operation
- argue about proof techniques.
